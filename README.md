Run the code with "python main.py {instance_name}" where instance_name can be one of the names in /src/Filenames.txt. The corresponding files (mps, aux, txt) have to be in /data/. All available parameters can be adjusted in /src/parameter_settings.py.
The results are stored in /results/csv/my_resultfile.csv and the name of the .csv file can be adjusted in /src/parameter_settings.py.
